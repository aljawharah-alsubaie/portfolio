About

What is Dreamverse?

Dreamverse is a conceptual AI-driven system that combines a mobile application with a smart sleep capsule. Users select the type of dream they want to experience — adventurous journeys, thrilling escapes, futuristic science-fiction worlds, or personal moments recreated from memory. This project focused entirely on the planning phase: defining scope, gathering requirements, and producing structured project management artifacts across multiple phases.

My Role — Project Manager

Led the full planning lifecycle — coordinated the team, defined project scope, managed requirements gathering through stakeholder interviews and surveys, and delivered all project management artifacts including WBS, Gantt chart, network diagram, and task allocation schedule.
