Find Differences
Game

A real-time multiplayer game where 2–4 players compete to spot differences between two images — built entirely with Java networking and sockets.

Java Socket Programming Multi-threading Java Swing Client-Server

About

What is this game?

Players connect to a central server, join a waiting room, and compete to find differences between two nearly identical kitchen scene images. The server handles up to 4 simultaneous players using multi-threading, running across three rounds with increasing point values (5, 10, 15 points). Highest score wins.

Gameplay

How to Play
