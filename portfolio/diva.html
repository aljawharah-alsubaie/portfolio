About

What was assessed?

DIVA (Damn Insecure and Vulnerable App) is an intentionally vulnerable Android application used for security training. This project involved conducting a full black-box security assessment — from reverse engineering the APK to dynamic runtime analysis — following the OWASP Mobile Security Testing Guide. Each vulnerability was documented with a proof of concept, severity rating, and remediation recommendation.

My Role

Security Analyst — conducted the full assessment independently: reverse engineering, dynamic analysis, vulnerability documentation, and writing the final security report.

Methodology

OWASP Mobile Security Testing Guide — structured phases: planning, information gathering, technical analysis, risk assessment, and documentation.
