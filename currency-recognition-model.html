Architecture

How It Works

The framework chains three models together: object detection first isolates the banknote, then a feature extractor captures visual details, and finally a classifier identifies the denomination.

1
YOLOv8
Detect & Crop
Localizes the banknote in the camera frame and crops it to a tight region of interest
2
MobileNetV2
Extract Features
Frozen ImageNet backbone extracts a 1280-D feature vector from the cropped banknote
3
SVM-RBF
Classify
Support Vector Machine with RBF kernel maps the feature vector to one of 7 denominations
4
Output
Announce Value
Result is spoken aloud via the assistive app — all in under 33ms end-to-end

Approach

Why a Hybrid Model?

Feature Extraction

MobileNetV2 Frozen

Pre-trained on ImageNet and kept frozen — no fine-tuning needed. Extracts rich 1280-D visual features with minimal compute.

Classifier

SVM over Softmax

SVM-RBF handles small datasets better than a fully trained CNN classifier, reducing overfitting on our 1,256-image set.

Localization

YOLOv8 RoI Crop

Detecting and cropping the note before classification removes background noise and makes the model robust to real-world conditions.
